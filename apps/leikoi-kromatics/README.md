# Leikoi Kromatics demo

Bouquet shop landing page with a tap-to-give story intro. React + react-three-fiber, built with Vite.

- `npm install` then `npm run dev` to work on it.
- `npm run build` builds and copies the result into the static site:
  `/demo-leikoi-kromatics.html` and `/demo/leikoi-kromatics/`. Commit those too, the site has no build step on Vercel.
- Shop contact details live in `src/config.js`.
- `?skip` opens the page without the story. `?t=3.2` holds the story at that second.
